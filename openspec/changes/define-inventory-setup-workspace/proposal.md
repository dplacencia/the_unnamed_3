# Inventory setup workspace

## Why

A merchant needs to see which Areas can handle stock before recording movements.
They also need to choose the channel available at a particular stock location
before recording a departure.

## Scope

Define and review the Inventory settings workspace for Core Area links, stock
location setup, departure channel creation and enablement. Use exact states and
responsive interactive Storybook fixtures in all five supported languages.

## Impact

The preview extends the existing Inventory settings entry. The owning Core and
Inventory contracts and the browser gateway stay independent.
