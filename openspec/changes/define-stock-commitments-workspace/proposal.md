# Define stock commitments workspace

## Why

Merchants need to reserve stock for an order, release an outstanding reservation, and record fulfillment once the goods leave. The approved journey distinguishes an outstanding reservation from both recorded on-hand stock and channel-specific availability.

## What changes

- Define one-product reservation, exact inspection, release and fulfillment in a responsive Movimientos preview.
- Surface separate authoritative reservation facts, signed physical effect and exact stock or channel availability when supplied by the fixture.
- Use review-only Storybook data while Inventory mutation, read, capability and replay interfaces remain deferred.
