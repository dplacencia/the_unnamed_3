# Make whole-batch duplicate cancellation easier to review

A merchant reviewing a duplicate in Pendientes must know which batch will be
cancelled, which lines it contains and which batch will be kept. Make those
roles clear in a Storybook walkthrough of the existing
[whole-batch cancellation](../define-pending-resolution-workspace/specs/pending-resolution-workspace/spec.md#requirement-prw-003--confirm-the-scope-of-whole-duplicate-cancellation).
Use the confirmed result to show both identities again and report its stock
outcome.
