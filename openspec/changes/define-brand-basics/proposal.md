# Define the product's brand basics

## Why

The repository foundation and visual workflow are implemented, and the user has
approved the current 368 comparison references. The user answered “go ahead” to
defining brand basics before customizing TailAdmin. Existing values and brand
personality provide a brief, while visual identity remains undefined.

## What Changes

- Discuss visual direction, then develop concrete colour and typography options
  from the user's choices, keeping recommendations distinct from adoption.
- Record approved basics and their scope before applying them to TailAdmin.
- Use real retained components and the existing visual workflow for subsequent
  comparisons; keep proposals separate from production branding.
- Preserve Irin as a provisional working name and retain the approved secular,
  warm, approachable and quietly confident positioning.

## Capabilities

### New Capabilities

- `brand-basics`: the selected restrained/approachable direction, ink indigo
  colour basis, Source Sans 3 typeface basis, simple provisional Irin text wordmark,
  retained TailAdmin component treatment, readable dark-brand text, and boundary
  between comparison proposals and production styling.

### Modified Capabilities

None. The existing scope, values, technology choices and reference approvals
remain intact.

## Impact

Work includes the development-only Storybook comparison and the approved first
backoffice configuration using retained TailAdmin components, the selected palette,
locally packaged Source Sans 3 and the provisional text wordmark. The visual
preparation/freshness tools cover the actual production font and retain historical
comparison fonts locally. The landing remains unchanged. The user-approved final
388 images replace the prior references through the guarded promotion workflow.
No package dependency, product flow, hosting, external integration or deployment
is included. The user's subsequent commit-preparation assignment authorizes
staging this completed branding batch; the user alone creates the commit.
